  * **Rol:** Arquitecto Backend & Database Designer.
  * **Descripción:** Diseño e implementación de la capa de persistencia relacional con PostgreSQL y lógica de negocio central en Django. Integración de canales de comunicación bidireccional en tiempo real mediante WebSockets (Django Channels) para la gestión automatizada de convocatorias universitarias.
  * **Stack:** `Python`, `Django`, `PostgreSQL`, `Django Channels`, `WebSockets`, `JavaScript`.

* **GroupsApp — Sistema de Mensajería Distribuida**
  * **Rol:** Lead Backend Engineer (Proyecto Telemática EAFIT).
  * **Descripción:** Orquestación de una arquitectura compleja basada en seis microservicios independientes bajo Docker Compose. Implementación de contratos de comunicación síncrona de alta eficiencia mediante gRPC / Protocol Buffers y procesamiento asíncrono de eventos con Apache Kafka.
  * **Stack:** `FastAPI`, `PostgreSQL`, `Apache Kafka`, `gRPC`, `Protocol Buffers`, `MinIO`, `Docker`.

* **AWS Auto Scaling Controller — Infraestructura Automatizada**
  * **Rol:** Cloud Systems Developer.
  * **Descripción:** Desarrollo de un motor de escalamiento automático para instancias EC2 utilizando Python y la API de boto3. Incorporación de telemetría basada en métricas personalizadas y supervisión mediante gRPC para el control dinámico del ciclo de vida de los nodos.
  * **Stack:** `Python`, `AWS EC2`, `boto3`, `gRPC`.

* **Casting Envigado — Ecosistema de Gestión de Medios Institucionales**
  * **Rol:** Fullstack Developer.
  * **Descripción:** Creación de una plataforma web optimizada para la indexación, consulta y distribución masiva de material fotográfico institucional con alta concurrencia de usuarios.
  * **Stack:** `React`, `Node.js`, `Python`, `PostgreSQL`.
